## 发现与修正

- 替同门理顺行气原有悟性历练 +3，但提示漏写；同类隐藏历练全部公开。历练是进度，不是属性立刻加三。
- 守灯辨字仍给予已失效的 insight，被 add 忽略，确实纯扣心神；现补为悟性历练 +2。
- 静听辩论原写悟性修习 +1，实际给 +2；现说明与实际一致。
- 守阵提示扣除已取消的研读经历，实际未扣；删除失效扣除文案。
- 心神、伤势恢复按实际可恢复量显示，临近属性上限的历练按实际剩余量显示；若所有收益已满，禁用白花资源的选项。
- 冒险进药圃、穿雾和破阵仍保留风险及明确提示；独探石髓池的低体魄伤势保留并补回归。
